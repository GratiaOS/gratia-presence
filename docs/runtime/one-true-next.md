# One True Next

_A runtime for choosing the next correct step._

---

## Why

Most productivity systems fail at the exact moment people need them most.

When stress increases, they expose:

- more todos
- more priorities
- more decisions
- more guilt

Gratia takes the opposite approach.

As cognitive load increases,
the interface becomes smaller.

The higher the pressure,
the fewer decisions remain.

At every moment the system exposes only one thing:

> **One True Next**

---

## Philosophy

Reality has many open loops.

Humans do not.

The nervous system can only execute one meaningful step at a time.

The purpose of Gratia is therefore not task management.

Its purpose is reducing reality into one executable movement.

One True Next does not replace judgment.

It is not the Companion's will.

It is a capacity-aware compression of what the actor has already offered, accepted, or made available.

The human still chooses.

## Companion Compression

Companion never owns agency.

It owns compression.

It does not decide.

It does not motivate.

It does not optimize.

It reduces noise between two moments of consciousness.

The actor may bring 3000 words.

The Companion may return:

> "Today, only send the HR documents."

This is not coaching.

It is not therapy.

It is not authority.

It is a compression engine.

The originality is not that Gratia selects a next task.

Many applications do that.

The originality is that Gratia selects the next executable movement according to the real capacity of the nervous system, not according to the abstract importance of a task.

## Modes

### Stabilize

Goal:

Reduce nervous system load.

Allowed:

- water
- food
- shower
- breathing
- short walk
- one administrative action

Forbidden:

- life decisions
- architecture
- planning
- optimization
- existential thinking

Output:

```text
ONE TRUE NEXT

Drink water.
```

or

```text
Send the signed contract.
```

Never both.

---

### Maintain

Goal:

Protect the foundation.

Examples:

- bills
- paperwork
- inbox
- onboarding
- documentation

Output:

```text
ONE TRUE NEXT

Upload certificate.
```

---

### Build

Enough energy exists.

Now architecture becomes available.

Examples:

- coding
- design
- writing
- strategy
- naming

Output:

```text
ONE TRUE NEXT

Implement Mode Router.
```

---

### Explore

Highest mode.

No pressure.

Only curiosity.

Examples:

- reading
- philosophy
- walking
- experimentation
- conversations
- research

Output:

```text
ONE TRUE NEXT

Read one paper.
```

## Design Principle

Gratia never asks:

"What do you want to accomplish today?"

Gratia asks:

"What can your nervous system honestly carry?"

Everything else follows from that answer.

Gratia never replaces judgment.

Gratia protects it.

When life becomes noisy,
the Companion removes noise,
until only the next honest step remains.

The human still walks.
